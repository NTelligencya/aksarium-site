The typing practice below wants a real keyboard layout, not a substitute; the drill reads whatever your operating system sends it. Both systems already carry every layout on this page, so nothing needs downloading or buying, and adding one takes about a minute.

On a Mac

Add itApple menu, System Settings, Keyboard, then Text Input and Edit. Use the add button, search for the language, and choose the layout.
See itIn the same panel, tick Show Input menu in menu bar. That menu is how you switch, and it also opens the viewer.
SwitchControl and space returns to your previous source; control, option and space steps forward through the list.
Find a keyInput menu, then Show Keyboard Viewer. Hold shift or option and the display redraws as that layer.

On Windows

Add itSettings, Time & language, Language & region. Click the ellipsis beside the language, then Language options and Add a keyboard.
New languageIf the language is not in your list yet, use Add a language first. A language pack only changes what Windows itself is written in; you do not need one in order to type.
SwitchWindows key and space steps forward, windows key, shift and space steps back. Ctrl and shift also switches layout.
Find a keySettings, Accessibility, Keyboard, then On-Screen Keyboard; or press windows, ctrl and O. It draws whichever layout is active.

The letters printed on your keys will not change. Both vendors point at the on-screen viewer as the way to find out which key produces which character; the alternatives are keycap stickers, or learning the positions, which is what the drill below is for.

Korean and Chinese are not layouts in the ordinary sense; what you add is an input method, and the software assembles the characters as you type. Windows files them under Add a keyboard regardless.
